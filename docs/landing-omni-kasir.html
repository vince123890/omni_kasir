Dari transaksi POS hingga opname stok, Omni Kasir menyediakan semua modul operasional untuk bisnis ritel Anda.

POS Transaksi Real-Time

Kasir pilih produk, sistem hitung total otomatis, bayar tunai. Transaksi tercatat langsung ke laporan pusat dalam hitungan detik.

Sprint 1 MVP

Multi-Store Management

Tambah banyak toko dalam satu akun bisnis. Setiap toko punya produk, kasir, dan stok sendiri yang terisolasi.

Sprint 1 MVP

Manajemen Stok Lengkap

Input stok masuk dari supplier, opname manual per produk dengan alasan selisih, konversi satuan (dus→pcs), dan alert stok menipis otomatis.

Sprint 1 MVP

Role-Based Access Control

4 peran terpisah: Admin Platform, Owner (view-only), Admin Store (operasional), dan Kasir. Setiap aksi dikendalikan JWT + RBAC ketat.

Keamanan Penuh

Dashboard & Laporan

Owner lihat performa semua toko sekaligus — total transaksi, omzet hari ini, kasir aktif. Filter laporan per toko, kasir, dan rentang tanggal.

Sprint 1 MVP

Multi-Tenant Aman

Isolasi data row-level via tenantId. Data bisnis Anda tidak pernah bocor ke tenant lain. JWT expired otomatis dalam 8 jam dengan refresh token 7 hari.

FAQ

Pertanyaan yang sering ditanyakan.

Apakah data bisnis saya aman dari tenant lain?
Ya, 100% aman. Omni Kasir menggunakan row-level isolation via tenantId. Setiap query ke database otomatis difilter berdasarkan tenant Anda. Data bisnis A tidak pernah bisa diakses oleh bisnis B dalam kondisi apapun.
Berapa banyak toko yang bisa saya kelola?
Tergantung paket. Basic mendukung 1 toko, Pro hingga 5 toko, dan Enterprise tidak terbatas. Upgrade atau downgrade bisa dilakukan kapan saja melalui admin platform.
Apakah kasir bisa login dari browser berbeda?
Ya. Omni Kasir berbasis web — bisa diakses dari laptop, tablet, atau HP dengan browser modern (Chrome/Firefox). Satu akun kasir hanya terikat ke satu toko, sehingga tidak bisa akses toko lain.
Bagaimana jika stok kasir tidak sesuai fisik?
Gunakan fitur Open Stok / Opname. Admin Store atau Kasir bisa input stok fisik per produk, sistem otomatis hitung selisih, lalu wajib isi alasan koreksi. Semua riwayat opname tersimpan dan bisa diaudit kapan saja.
Apakah ada biaya tambahan untuk kasir?
Tidak ada biaya tambahan per kasir di paket Pro dan Enterprise. Jumlah kasir tidak dibatasi. Paket Basic memiliki batas 2 kasir per toko untuk menjaga performa sistem.
Bagaimana cara perpanjang subscription?
Admin platform akan memperpanjang subscription Anda berdasarkan pembayaran. Owner akan menerima notifikasi alert di dashboard jika subscription tinggal 7 hari lagi — cukup hubungi admin untuk perpanjang.
