Masalah Nyata

Kelola banyak toko
itu melelahkan.

  • Data toko berserakanLaporan toko A ada di Excel, toko B di buku tulis. Susah rekap omzet total.
  • Stok tidak terpantauBarang habis baru ketahuan saat pelanggan mau beli. Kehilangan penjualan setiap hari.
  • Rekap manual makan waktuOwner harus pergi ke tiap toko untuk rekap. Tidak bisa pantau dari rumah.
Solusi Omni Kasir

Semua terpusat,
semua terkontrol.

  • Dashboard terpusat — pantau semua toko, semua kasir, semua transaksi dari satu layar.
  • Stok real-time — alert otomatis saat stok menipis, tidak ada lagi barang habis tak terduga.
  • RBAC ketat — kasir hanya akses POS, admin store kelola produk, owner view laporan. Tidak ada data bocor.
  • Multi-tenant isolasi penuh — data bisnis Anda tidak pernah bercampur dengan bisnis lain.
  • Akses dari mana saja — web-based, tidak perlu install. Buka dari HP, laptop, atau tablet.
Fitur Lengkap

Semua yang Anda butuhkan,
sudah tersedia.

Tidak perlu integrasi tambahan. Omni Kasir hadir dengan semua fitur operasional toko dalam satu paket.

POS Transaksi

Tampilan kasir yang bersih dan cepat. Cari produk, tambah ke keranjang, hitung kembalian otomatis. Dirancang untuk kecepatan.

Race Condition Safe

Manajemen Stok

Stok masuk, konversi satuan (dus → pcs), open stok / opname dengan alasan selisih. Riwayat lengkap setiap pergerakan stok.

BL-013 Compliant

Laporan & Dashboard

Dashboard owner tampil omzet semua toko, transaksi hari ini, kasir aktif. Filter per store, per kasir, per tanggal.

Real-time

Multi Kasir & Toko

Tambah kasir dan admin store per toko, batasi sesuai plan. Owner kelola semua toko, kasir hanya akses toko sendiri.

RBAC 4 Role

Keamanan JWT

Access token 8 jam, refresh token 7 hari. Setiap request divalidasi role dan tenantId. Data terisolasi per bisnis.

Stateless JWT

Teknologi Modern

ReactJS + NestJS + MySQL + Docker. Response API <2 detik. Siap deploy ke VPS atau cloud. Open untuk kustomisasi.

Cara Kerja

Mulai dalam 5 menit.

Tidak perlu instalasi, tidak perlu konfigurasi server. Daftar, isi data bisnis, langsung pakai.

1

Daftar & Pilih Plan

Pilih Basic, Pro, atau Enterprise sesuai jumlah toko dan kasir Anda. Bayar bulanan, batalkan kapan saja.

2

Setup Toko & Produk

Tambahkan toko, input produk beserta harga dan stok awal. Admin Store Anda siap menggunakan dalam hitungan menit.

3

Undang Tim Kasir

Buat akun kasir dan admin store per toko. Mereka langsung bisa login dan mulai transaksi dari browser manapun.

4

Pantau dari Dashboard

Sebagai Owner, lihat omzet semua toko real-time. Laporan transaksi, riwayat stok, semua dalam satu halaman.
